# 🔐 Tela de Login e Cadastro Moderna

Projeto simples e estilizado com foco em **login** e **cadastro de usuários**, utilizando apenas **HTML**, **CSS** e **JavaScript**. Ideal para integrar em sistemas maiores ou usar como base de estudos.

## 🎯 Objetivo

Oferecer uma interface moderna e responsiva para que o usuário possa:

- Criar uma conta
- Fazer login com os dados cadastrados
- Visualizar feedback de validações básicas (como campos obrigatórios)

## 🧠 Tecnologias Utilizadas

- HTML5
- CSS3 (com design moderno)
- JavaScript (para validações e interatividade)

## 📁 Estrutura de Arquivos

- `index.html` – Tela de login
- `cadastro.html` – Tela de cadastro
- `style.css` – Estilo visual do projeto
- `script.js` – Lógica de validação e interações

## 💡 Funcionalidades

- Alternância entre tela de login e cadastro
- Validação de campos obrigatórios
- Interface responsiva
- Estilo moderno com animações suaves
